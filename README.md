# VDJ Kontrol S8

Skins and controller mappings for the Traktor Kontrol S8, made for VirtualDJ.

## Skins

Skins for the S8's two built-in screens — because the stock screens are a little boring.

- **[Trans-Pride/](Skins/Trans-Pride/)** — 🏳️‍⚧️ Trans Pride 🏳️‍⚧️ themed skin (blue/pink/white). See its README for the full feature list and screenshots.

  <img src="Skins/Trans-Pride/Samples/main.webp" alt="Trans pride themed deck view on the S8 screen" width="400"/>
  <img src="Skins/Trans-Pride/Samples/browser.webp" alt="Trans pride themed browser view on the S8 screen" width="400"/>

More skins may get added over time. Grab a `.zip` and drop it in your VirtualDJ `Skins` folder to use one.

## Mappings

Custom controller mappings for the S8.

- **[Mappings/](Mappings/)** — **butt3rpuppie's** custom mapping, built on the stock `TRAKTORS8` mapper with a scratch-style shift+jog, tempo-nudge encoder, fast browser scrolling, and a few other tweaks. See its README for the full list of differences from the default mapping and install steps.
